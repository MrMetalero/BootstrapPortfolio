# Portfolio Website

A modern and responsive personal portfolio website built with HTML, CSS, and Bootstrap. This project is designed to present your profile, skill set, projects, and contact information in a clean and professional layout.

## English

### Overview
This portfolio website is a single-page personal landing page intended to showcase usage of bootstrap and mobile first design

### Features
- Responsive and modern layout
- Main section with presentations
- About me section
- Skills and technologies overview
- Projects showcase cards
- Contact section with social links or contact form
- Clean and professional visual design

### Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- JavaScript

### How to Run the Project
1. Download or clone the project repository.
2. Open the `index.html` file in your browser, or run a local server in the project folder.
3. If you prefer using a local server, run:

```bash
npx serve .
```

### Project Structure
- `index.html` — main page structure
- `css/` — custom styles
- `js/` — JavaScript files
- `assets/` — images, icons, and other static files
